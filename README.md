# Wishlist

Список желаний на телефоне и на компьютере. Ссылку можно вставить — название, цена и фото подтянутся, если страница их отдаёт. Всё остальное правится руками.

Данные остаются на устройстве (IndexedDB). Аккаунт не нужен.

- Главный экран: сумма, фильтры, карточки, поиск, порядок перетаскиванием
- Добавление и правка в шторке
- Архив, восстановление и удаление
- Светлая и тёмная тема
- Экспорт и импорт JSON
- Установка на экран «Домой» (PWA)

Ссылка на товар читается на сервере приложения: обычная статическая страница GitHub Pages страницу магазина открыть не может.
